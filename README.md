# Indidnt
As someone who has learned a variety of languages over the course of his life, one aspect of certain languages always seemed to rub me the wrong way. While languages like Python are incredibly powerful, writing code for them, especially in less powerful IDEs, can be very difficult for the sole reason of indentation. 

Indentation, or off-side, is a convention that began with ISWIM in 1966, and was later adopted by Haskal, Miranda, Python, and others. While it may have its advantages, for those who are either more comfortable with C-based languages or just prefer the certainty of bracketed code, this tool is for you.

Indidnt allows users to convert between these structure conventions, replacing bracketed code with indented code, and vise-versa. It was built using C# and WinForms, as a standalone Windows application.

I'd like to make it clear that there is nothing inherently wrong with languages that use indentations as their code structure, just that some developers or situations may call for a more familiar convention.
